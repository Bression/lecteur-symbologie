Résultat

Historique

Stocké uniquement sur ce téléphone (200 derniers scans).

    Aide

    Utilisation

    • Visez le code : l'analyse est automatique, le téléphone vibre et bipe à la lecture.
    • Pour un petit code, rapprochez-vous puis utilisez le zoom. Sur iPhone Pro, essayez le bouton Caméra pour passer sur l'objectif macro / ultra grand-angle.
    • Photo : analyse une image de la galerie (par ex. une photo envoyée par le client). L'analyse y est plus poussée qu'en direct.
    • Plusieurs codes dans l'image : tous sont listés.

    Installer sur le téléphone

    • iPhone (Safari) : bouton Partager → « Sur l'écran d'accueil ».
    • Android (Chrome) : menu ⋮ → « Installer l'application » / « Ajouter à l'écran d'accueil ».

    Une fois installée, l'appli fonctionne hors connexion.

    Confidentialité

    Le décodage est fait entièrement sur le téléphone. Aucune image ni donnée n'est envoyée sur Internet. L'historique reste dans le téléphone.

    Limites

    • Les codes en marquage direct (micro-percussion, gravure laser sur métal) sont souvent difficiles à lire avec un téléphone.
    • La « marge de correction restante » est indicative : ce n'est pas un grade de qualité ISO 15415 / 15416.
